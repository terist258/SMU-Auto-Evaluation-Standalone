# 南医大评课助手 · 独立版

不依赖 DeepSeek Harness 的绿色版，自带 Node 运行时和 Playwright，**双击 `南医大评课助手.exe` 即可使用**。

主要功能：

- **随堂评价**：每天定时自动评今天+昨天的课（2 四星 + 2 五星 = 90 分，可配置）
- **期末评课程**：学期末把未评价的课逐门打满五星并提交（支持 wjiaowu 微信 Token 和 zhjw 正方系统两种渠道）
- **Token 自动续期**：电脑版微信浮窗自动刷新，失效后自动补跑
- **Windows 计划任务**：每天定点运行，关闭程序也不影响
- **失败弹窗提醒**：评课失败时弹置顶红卡，不漏掉任何一次

---

## 快速上手

1. **双击「南医大评课助手.exe」**（或桌面快捷方式）—— 不会弹黑框，会自动启动后台服务并打开操作界面（`http://127.0.0.1:17320`）。
2. **退出程序**（任选一种）：
   - 界面右上角「退出程序」按钮（会二次确认）
   - 右键任务栏右下角托盘图标 → 「退出程序（停止服务）」
   - 双击桌面「停止评课助手」快捷方式
3. **首次使用**：在界面的「Token」页签点「扫描 Token」，确认能拿到有效登录态；再到「操作」页签先「试运行（不提交）」看流程，确认无误后「立即执行」。
4. **定时**：到「定时」页签设好时间，点「注册 Windows 计划任务」，之后关掉程序也会照常跑。

| 页签 | 用途 |
|------|------|
| Token | 扫描/刷新微信 Token，查看 Token 有效期和账号信息 |
| 操作 | 随堂评价立即执行 / 试运行；期末评课程立即执行 / 试运行 |

| 评课程 | 学期末点一次「评价本学期课程」 |
| 日志 | 查看运行日志和历史回执 |

## 渠道说明（随堂评价）

| 渠道 | 说明 | 适用场景 |
|------|------|----------|
| wjiaowu | 走微信电脑版 Token，页面内 fetch 评课 | 主渠道，最稳定 |
| zhjw | 走正方系统账号密码 + 验证码，浏览器键鼠模拟 | 备选渠道，wjiaowu 不可用时使用 |

zhjw 渠道三种模式（在配置里选）：

- **keyboard-mouse**（推荐，默认）：全程键鼠模拟，登录后不发任何页面内 fetch，全部点真实页面，最像真人操作
- **browser**：键鼠登录后，页面内 fetch 评课
- **http**：纯 HTTP 备选（不推荐，指纹容易被识别）

## 期末评课程（学期末使用）

配置面板里有一块 **「期末评课程（手动）」**，只有学期末开放时才用，**平时每天的自动随堂评价完全不包含它**。

作答策略：

- 12 道星题全部「非常赞同」→ 综合评分 **100**
- 「你担任的职务」→ **无职务**
- 「本学期是否达到课程学习要求」→ **按要求完成了学习**
- 「其他意见或建议」→ 填一句模板；「优秀教师姓名」→ 留空
- 第 15 题「自主学习比例」→ 下拉菜单选 **课程学时 30% 以内**

操作按钮：

| 按钮 | 行为 |
|------|------|
| 评价本学期课程 | 把所有未评价的课逐门打满五星、按常规选项作答并提交 |
| 试运行（不提交） | 走一遍同样的流程，最后不点提交，用来核对分数 |

> 提交后不可撤销，第一次用建议先点「试运行」看看分数。

**zhjw 渠道期末评课程**：走正方系统账号密码登录，在欢迎页点「评价信息」→ 子项「课程评价」，进入 iframe 内的评教页面，逐门操作。系统处于维护期时直接打评教地址会 404，需等系统恢复。

## 配置文件

所有配置统一存放在：

```
%LOCALAPPDATA%\smueval-bot\config.json
```

DSH 插件版与独立版共用同一份配置，两边切换不用重新配。

同目录下的其他文件：

| 文件 | 内容 |
|------|------|
| `last-run.json` | 最近一次随堂评价结果 |
| `last-course-run.json` | 最近一次期末评课程结果 |
| `runs.jsonl` | 历史记录（一行一次） |
| `run.log` | 运行日志 |
| `standalone-run.cmd` | 计划任务实际调用的批处理（自动生成） |

常用配置项（可在界面改，或手动编辑 config.json）：

| 字段 | 说明 | 默认值 |
|------|------|--------|
| `channel` | 评课渠道：`wjiaowu` / `zhjw` / `auto` | `wjiaowu` |
| `zhjwMode` | zhjw 模式：`keyboard-mouse` / `browser` / `http` | `keyboard-mouse` |
| `zhjwAccount` | zhjw 统一身份认证账号 | —— |
| `zhjwPassword` | zhjw 密码（AES-256-GCM 加密存储，`enc:` 开头） | —— |
| `runTimes` | 每天运行时间，可写多个 | `["20:30"]` |
| `runJitterMinutes` | 时间随机浮动分钟数 | `30` |
| `lookbackDays` | 往前补几天（今天+昨天） | `1` |
| `catchUpOnStart` | 错过定时点后启动补跑 | `true` |
| `fourStarCount` | 四星题数量 | `2` |
| `varyFourStar` | 四星数量是否随机浮动 | `false` |
| `suggestionEmptyRate` | 建议栏留空概率 | `0.35` |
| `courseAllFiveStars` | 期末评课程是否全五星 | `true` |
| `courseMaxPerRun` | 单次最多评几门课 | `20` |
| `headless` | 是否隐藏浏览器窗口 | `false` |
| `systemTask` | 是否注册 Windows 计划任务 | `false` |

> `zhjwPassword` 以 `enc:` 开头的 AES-256-GCM 密文存储，明文绝不出现在代码、仓库、发布包或日志里。

## 命令行用法

在独立版目录下用自带的 Node 运行：

```
node\node.exe run-once.mjs                 # 立刻跑一轮随堂评价
node\node.exe run-once.mjs --jitter        # 先随机等一会儿（像计划任务那样）
node\node.exe run-once.mjs --dry-run       # 只点不提交
node\node.exe run-once.mjs --check         # 只看配置
node\node.exe run-once.mjs --refresh-token # 只刷新 Token
node\node.exe run-once.mjs --test-notify   # 测试失败弹窗
node\node.exe run-course.mjs [--dry-run]   # 期末评课程
```

## 注意事项

- **需要本机已安装 Microsoft Edge**（或 Chrome）——自动化用的是真实浏览器，不是内置内核
- **计划任务和 DSH 插件版共用任务名**（`smueval-bot-2030`）。在独立版里点「注册计划任务」会把它指向本目录；想换回 DSH，就在 DSH 面板里重新开关一次
- **Token 续期要操作微信窗口**：必须是已登录的桌面会话（锁屏无效），且电脑版微信的浮窗里要有「教学服务平台系统」（手机微信里从「南医大教学」→「本科」进教务系统 → 右上角「···」→ 浮窗，一次性设置）
- 把整个文件夹拷到别的 Windows 电脑上也能直接跑（前提是那台机器装了 Edge、有微信登录态）
- **不要把 config.json 拷贝到别的电脑或上传到网络**：里面包含加密后的 zhjw 密码和 Token 相关信息

## 故障排除

**Q：提示「未找到可用的浏览器」**

装 Edge 或 Chrome，或者在配置里用 `browserPath` 指定浏览器 exe 的完整路径。

**Q：提示「所有 Token 均已失效」**

在**电脑版微信**里打开一次 `https://wjiaowu.smu.edu.cn/`。注意手机微信无效——手机上的数据不会写到这台电脑。

**Q：窗口弹出来又关掉，什么都没评**

看界面「日志」页签或 `%LOCALAPPDATA%\smueval-bot\run.log`。常见原因是当天没有可评课节（课时未结束会显示「时间未到」）。

**Q：期末评课程点进去是 404 / 系统维护**

正方系统可能处于维护期，直接打评教地址会被拦回。等学校系统恢复后再试。也可以在配置里把「课程评价页地址」填成你亲手在浏览器里能打开的那个完整网址。

**Q：Token 续期失败**

确保电脑版微信已登录，且浮窗里已添加「教学服务平台系统」。锁屏状态下续期会失败。

**Q：想完全自动，不想管 Token**

学校的登录是微信静默授权，只能在微信客户端内部触发，外部无法复现；手工点一次浮窗的方案已经是成本最低的了。

## 隐私与安全

- 配置文件 `config.json` 仅存在于本机 `%LOCALAPPDATA%\smueval-bot\`，**从不上传任何服务器**
- `zhjwPassword` 以 `enc:` 开头的 AES-256-GCM 密文存储，明文绝不出现在代码、仓库、发布包或日志里
- 发布前会对仓库工作区与全部 git 历史做隐私扫描，确保不包含学号、账号、Token、密码、主机名、绝对路径等敏感信息
- 本程序通过自动化代替人工操作学校系统，使用前请自行确认这符合学校的相关规定，由此产生的一切后果由使用者自行承担
